## Бекенд для приложения RTSU-students

## Клонируйте проект
```bash
    git clone https://github.com//shodruzxoshimzoda/RTSU-students
```

### Установите зависимости: 
```bash
    go mod tidy
```

### Настройк: 
    Создайте: 
        1) Базу Данных PostgreSQL под названием rtsu и пользователья для него
        2) Дайте привелегии на использования всех методов вашему пользователю БД
        3) Настройте конфигурационный файл local.yaml под вашего пользователья и .env файл
        4) Настройте файле .env
        

### Запустите сервер
    1) `go run ./cmd/api`
    
    2) `make server run`    

## Примечание
    1) Подразумевается что у вас уже установлен язык Go
    2) Для работы с make нужно дополнительно установить make 
            В случае Linux - `sudo apt install make`
            В случае Windowd - фиг его знает сами  установите :)
